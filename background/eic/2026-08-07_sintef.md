# EIC Transition — Preliminary Work Packages and Tasks

Preliminary structure prepared by SINTEF (Balram Panjwani) for the joint EIC Transition proposal on SUREWAVE-based offshore FPV. Converted from `2026-08-07_sintef.docx` via pandoc, then reformatted into readable Markdown.

## WP1. Project Management and Innovation Management

### Task 1.1 Project Coordination

- Consortium management
- Progress monitoring
- Reporting to EIC

### Task 1.2 Risk and Quality Management

- Technical risk register
- Mitigation actions
- Quality assurance procedures

### Task 1.3 Innovation and Commercialization Management

- IP management
- Freedom-to-operate assessment
- Exploitation roadmap

## WP2. Design Optimization of the SUREWAVE FPV System

### Task 2.1 Requirement Definition

- Definition of demonstration objectives
- Site-specific design criteria
- Environmental conditions

### Task 2.2 Floating Breakwater Optimization

- Hydrodynamic design refinement
- Structural optimization
- Circular material integration

### Task 2.3 FPV Platform Design

- Layout optimization
- Integration of PV and dummy modules
- Maintenance considerations

### Task 2.4 Mooring and Anchoring System Design

- Site-specific mooring design
- Reliability assessment
- Extreme load analysis

## WP3. Design and Performance Assessment

### Task 3.1 Numerical Modelling

- Coupled hydrodynamic analysis
- Structural response modelling
- Mooring simulations

### Task 3.2 Energy Yield Assessment

- Impact of motions on PV performance
- Shading analysis
- Salt deposition effects

### Task 3.3 Model Development

- Real-time monitoring framework
- Model validation methodology

## WP4. Instrumentation and Monitoring System Development

### Task 4.1 Monitoring Requirements

- Structural monitoring requirements
- Energy monitoring requirements

### Task 4.2 Sensor System Development

- Load measurement systems
- Motion sensors (IMU)
- Water ingress monitoring
- Corrosion monitoring

### Task 4.3 Data Acquisition Platform

- Data communication architecture
- Cloud-based data storage
- Dashboard development

## WP5. Demonstrator Construction and Integration

### Task 5.1 Prototype Manufacturing

- Floating structures
- Breakwater components
- Mooring components

### Task 5.2 PV and Dummy Module Integration

- Installation procedure
- Electrical integration
- Structural integration

### Task 5.3 System Assembly and Factory Testing

- Pre-deployment validation
- Safety verification

## WP6. Demonstration Site Preparation, Permitting and Deployment

### Task 6.1 Site Selection and Technical Feasibility

- Selection of final demonstration site
- Comparison of Aguçadoura and alternative locations
- Assessment of metocean conditions
- Grid availability assessment (if required)
- Maritime logistics assessment

### Task 6.2 Permitting and Regulatory Compliance

- Mapping of permitting requirements
- Engagement with maritime authorities
- Environmental permitting process
- Navigation and marine safety assessment
- Stakeholder consultations
- Preparation of permit applications
- Potential permits and approvals:
  - Maritime occupation permit
  - Environmental approval
  - Port authority approval
  - Navigation safety clearance
  - Temporary offshore installation permit
  - Electrical installation approval (if power export is included)

### Task 6.3 Environmental and Social Impact Assessment

- Baseline environmental review
- Marine ecosystem interaction assessment
- Fisheries and stakeholder consultation
- Visual impact assessment
- Decommissioning considerations

### Task 6.4 Demonstrator Installation Planning

- Installation methodology
- Vessel requirements
- HSE procedures
- Risk assessment
- Emergency response plan

### Task 6.5 Offshore Installation and Commissioning

- Mooring installation
- Deployment of breakwater structure
- Deployment of FPV platform
- Installation of monitoring systems
- Functional testing and commissioning

## WP7. Operational Validation and Data Collection

### Task 7.1 Structural Validation

- Load measurements

### Task 7.2 Reliability Assessment

### Task 7.3 Energy Performance Assessment

### Task 7.4 Model Validation

- Comparison with design tools
- Improvement of prediction models

# EIC Transition — Preliminary Work Packages and Tasks (with partner assignments)

Working document from the consortium; evolves the preliminary structure from 2026-08-07. This version adds partner-lead assignments per WP and per task.

Template header from the source document:

> **Table 3.3b: Work package description**
> Work package number, Work package title, Objectives, Description of work — one such block per WP in the final proposal.

## WP1. Project Management and Innovation Management (SINTEF)

### Task 1.1 Project Coordination

- Consortium management
- Progress monitoring
- Reporting to EIC

### Task 1.2 Risk and Quality Management

- Technical risk register
- Mitigation actions
- Quality assurance procedures

### Task 1.3 Innovation and Commercialization Management

- IP management
- Freedom-to-operate assessment
- Exploitation roadmap

## WP2. Design Optimization of the SUREWAVE FPV System (SiS)

### Task 2.1 Requirement Definition (SiS)

- Definition of demonstration objectives
- Site-specific design criteria
- Environmental conditions

### Task 2.2 Floating Breakwater Optimization (Clement)

- Hydrodynamic design refinement
- Structural optimization
- Circular material integration

### Task 2.3 FPV Platform Design (SiS)

- Layout optimization
- Integration of PV and dummy modules
- Maintenance considerations

### Task 2.4 Mooring and Anchoring System Design (Clement/WavEC)

- Site-specific mooring design
- Reliability assessment
- Extreme load analysis

## WP3. Design and Performance Assessment (SINTEF/EDP)

### Task 3.1 Numerical Modelling (SINTEF/WavEC)

- Coupled hydrodynamic analysis
- Structural response modelling
- Mooring simulations

### Task 3.2 Energy Yield Assessment (EDP/SiS)

- Impact of motions on PV performance
- Shading analysis
- Salt deposition effects

### Task 3.3 Model Development (EDP/SINTEF)

- Real-time monitoring framework
- Model validation methodology
- Loads on different components

## WP4. Instrumentation and Monitoring System Development (WEC)

### Task 4.1 Monitoring Requirements (SiS)

- Structural monitoring requirements
- Energy monitoring requirements

### Task 4.2 Sensor System Integration (WEC)

- Load measurement systems
- Motion sensors (IMU)
- Water ingress monitoring
- Corrosion monitoring

### Task 4.3 Data Acquisition Platform (WEC/SINTEF)

- Data communication architecture
- Cloud-based data storage
- Dashboard development

## WP5. Demonstrator Construction and Integration (Clement)

### Task 5.1 Prototype Manufacturing Breakwater (Clement)

- Breakwater components
- Mooring components

### Task 5.2 Prototype Manufacturing PV module (SiS)

- PV components
- Connection system (hinges, breakwater to PV module)

### Task 5.3 System Integration (EDP/SiS/WEC)

- Installation procedure
- Mechanical integration
- Electrical integration (invertors, dissipation, grounding)

### Task 5.5 Acceptance and Factory Testing (SiS)

_Note: T5.4 is missing in the source document._

- Pre-deployment validation
- Safety verification

## WP6. Demonstration Site Preparation, Permitting and Deployment (WEC)

### Task 6.1 Environmental (metocean) and Technical Feasibility (WEC)

- Comparison of Aguçadoura and alternative locations (Coastal area)
- Assessment of metocean conditions
- Maritime logistics assessment

### Task 6.2 Regulatory Compliance (WEC)

- Engagement with maritime authorities
- Environmental permitting process
- Navigation and marine safety assessment
- Stakeholder consultations
- Preparation of permit applications
- Potential permits and approvals:
  - Maritime occupation permit
  - Environmental approval
  - Port authority approval
  - Navigation safety clearance
  - Temporary offshore installation permit
- Environmental and Social Impact Assessment:
  - Baseline environmental review
  - Marine ecosystem interaction assessment
  - Fisheries and stakeholder consultation
  - Visual impact assessment
  - Decommissioning considerations

### Task 6.2 Demonstrator Installation Planning (WEC/EDP/SiS)

_Note: This task is listed as T6.2 in the source but should probably be T6.3._

- Installation methodology
- Vessel requirements
- HSE procedures
- Risk assessment
- Emergency response plan

### Task 6.3 Offshore Installation and Commissioning (L:Clement; P:All)

- Mooring installation
- Deployment of breakwater structure
- Deployment of FPV platform
- Installation of monitoring systems
- Functional testing and commissioning

## WP7. Operational Validation and Data Collection (L:SINTEF)

### Task 7.1 Structural Validation (L:SINTEF, P:ALL)

- Load measurements
- Fatigue assessment
- Motion validation

### Task 7.2 Reliability Assessment (L:SiS)

- Water ingress assessment
- Corrosion assessment
- Equipment reliability

### Task 7.3 Energy Performance Assessment (L:EDP)

- PV production analysis
- Impact of wave-induced motions

### Task 7.4 Model Validation (L:EDP)

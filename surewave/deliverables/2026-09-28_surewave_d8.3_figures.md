# SUREWAVE D8.3 Technical Brochure — Figures companion

Descriptions of every image referenced in the D8.3 technical brochure by `[[FIGURE-N · ...]]` placeholder. Each entry is written to be pasted into an image-generation tool (ChatGPT / DALL·E / Midjourney / similar), together with the `surewave/2026-09-28_status.md` status document for project context. For photographs the entry describes what a suitable image would show and where it should come from.

Style guidance that applies to all figures unless overridden per figure:

- Colour palette: cool marine tones (deep blue, teal, cool grey) as base; warm accent (amber / muted orange) for solar / heat / attention elements; concrete off-white for structural surfaces; steel dark grey for mooring / cabling. Avoid saturated primary reds and greens.
- Style: clean flat vector or lightly-shaded technical illustration for diagrams and cross-sections; photorealistic for concept renders and cover art; annotated engineering-drawing style for dimensioned units.
- Typography in labels: sans-serif, medium weight, moderate size — legible in a print brochure at 40–60% figure width.
- Do not include any human faces or identifiable persons unless the source is an existing consortium photograph.
- Do not include any competitor product branding, only SUREWAVE / consortium partner naming where explicit.
